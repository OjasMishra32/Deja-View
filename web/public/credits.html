Credits

Déjà View was built at SwampHacks XII, and all of our own code was written during the event. It stands on the open‑source models, libraries, tools, services and media below.

A licence is listed where our project records it. “See upstream” means we haven’t recorded it, and the project’s own licence applies.

Models

  • FlashWorldimlixinyang/FlashWorld, rev 424db448
    Photo mode: one photo, screenshot or sentence becomes a whole world.
    Apache-2.0 (code); weights: see upstream
  • Wan2.2-TI2V-5BWan-AI/Wan2.2-TI2V-5B-Diffusers
    The video model FlashWorld is built on (VAE, UMT5 text encoder, transformer config).
    Apache-2.0
  • Qwen2.5-VL-3B-InstructQwen/Qwen2.5-VL-3B-Instruct
    FlashWorld’s captioner.
    See upstream
  • AnySplatInternRobotics/AnySplat, rev 5f5e208a
    Many photos become a splat world in one pass.
    MIT (code); weights: see upstream
  • VGGTfacebook/VGGT-1B
    AnySplat’s geometry backbone.
    See upstream
  • Depth Anything V2Metric Indoor Small and Base, depth-anything
    Per-frame depth for Video mode, the depth term when rebuilding a place, and lifting generated fill into 3D.
    See upstream
  • DeepLabV3torchvision, ResNet-50 and MobileNet
    Person masks, so people don’t get baked into the room.
    See upstream
  • Big LaMaadvimman/lama, file from simple-lama-inpainting
    Inpainting the empty room behind people, and small fills.
    Apache-2.0
  • Qwen-Image-Edit-2511Qwen/Qwen-Image-Edit-2511
    Paints what the photos never saw (the ceiling, tree tops, the sky) and the back of each 3D person.
    Apache-2.0
  • Qwen2.5-VL-7BQwen-Image-Edit-2511’s text encoder
    Describes what belongs in each gap before it is painted.
    See upstream
  • Multi-HMR 2NAVER, naver/multi-hmr2, commit f066532d
    Body pose and shape per frame for the 3D people.
    Non-commercial licence (code and checkpoint), plus BEDLAM and AnnyOne terms
  • Anny body modelNAVER, anny 0.6.0
    The body the 3D people are built on.
    Apache-2.0 code, CC0 assets
  • DINOv3 backbone codeFetched by torch.hub at run time
    Multi-HMR 2’s image backbone.
    DINOv3 License
  • SAM 2.1facebook/sam2.1-hiera-large and -small
    Object masks.
    Apache-2.0
  • Grounding DINOIDEA-Research/grounding-dino-tiny
    Text prompts to boxes for the object vocabulary.
    Apache-2.0
  • TRELLISmicrosoft/TRELLIS-image-large
    Optional image-to-3D props.
    MIT

No SMPL-family file is installed or used. Model weights are never committed to the project; each one is downloaded at setup.
